# 混合したゲーム変換の整合性と局所修復：次の定理の仕様

現在の中心候補は、横合成・値の複製・破棄を含む具体的な暗号証明の変換体系に、有限な局所比較図式を構成し、その内部条件を保持して変更後の証明を修復することです。この文書は研究上の仕様です。以下の一般定理と混合体系の完全性は、まだLeanで証明していません。新規性も未確定です。

## 現在の証拠が示した範囲

通常の推論にも同じ局所補題と共有を認めると、現在の規則の表示では、高次図式と通常の導出を同じ規則の木を保って相互に移せます。認証符号の経路族では、専用の通常の構成とその図式解釈がともに `5n+2` 節点になります。根拠は `GameProofOrdinaryErasure.lean` と `GameProofOrdinaryMAC.lean` の定理です。[検証と実験](experiments/oracle-game-proof-ordinary-baseline.json)を保存しています。

このため、共有と専用化による短さだけを投稿の中心にはしません。一方、異なる証明体系のすべてで高次元の利点が不可能だと示したわけではありません。次の課題は、利用者が全経路の比較証明を与えずに済む、具体的な有限の局所図式を構成できるかです。通常の方法でも同じ図式生成器を実装できる可能性を比較から除外しません。

## 先行研究との対応

Fritz–Liangの [Free gs-Monoidal Categories and Free Markov Categories](https://link.springer.com/article/10.1007/s10485-023-09717-0) の定義2.1、定理4.1、§6の正規化、補題6.5と定理6.6の該当本文を再確認しました。複製・破棄を持つ自由な図式と解釈は既存の構成です。これを、そのまま誤差・内部条件・実行資源を保持する高次基底の定理とは扱いません。全文・全図の読了や成果物の再現は今回も行っていません。

Dupont–Malbosの [Coherent confluence modulo relations and double groupoids](https://arxiv.org/abs/1810.08184) の第3版PDFから、定義4.2.1・4.3.8・5.1.3、定理5.2.3・6.2.2と系6.2.4、§6.1–6.2の該当説明を確認しました。定理6.2.2はEに関する正規化と、Γによる合流性・停止性およびEの収束性を仮定します。補完は臨界分岐の図式だけでなく、Eの作用・離れた書換えの交換・E側の整合性も含みます。「構造法則を同一視すれば、局所合流だけで有限な高次基底が得られる」という主張にはしません。PDF全体の読了と図の視覚的確認は未実施です。

局所比較から大域的な整合性を得る原理は、これらの先行研究との差分にはなりません。新規性の候補は、対象の暗号的な体系で仮定を実際に満たす有限な図式の構成と、条件・保証・実行証拠を失わない修復への具体的な接続です。この候補についても先行研究からの還元を調べる必要があります。

## 対象とする構造を分けます

ゲームの図は、型付きの確率的な操作の箱と、抽選済みの値を扱う配線から構成します。配線には横合成、複製、破棄を含めます。二つの独立なゲームの積と、同じ実行記録の複製は区別します。共有オラクルの状態を、独立な状態の積に置き換えません。

複製を確率的な箱の前後で無条件に移動する規則は置きません。`Copyability.kernel_copyable_iff_deterministic` は、現在の離散分布の意味論で、その移動が任意の入力に対して成立するための決定性の条件をすでに証明しています。これは既知の原理の形式化です。

また、確率分布の出力が同じでも、実行資源や割当て誤差が同じとは限りません。箱の出力を破棄しても、その箱を実行した費用まで無条件に消してはいけません。厳密な保存を要求する高次比較と、費用が減る有向の改善は別の関係にします。既存の `ResourceImprovement` では、後続の合成に資源の単調性を要求しています。単調性を、実行の正しさだけから推論しません。

これらの区別は、次の仕様への入力条件です。混合構文・正規化・全高次基底への接続が完了したという意味ではありません。

## 定理候補A：具体的な有限の局所図式から比較を構成します

構造変形の規則をE、暗号的な変換の規則をRとします。Γは、同じ局所分岐を解消する比較図式の集合です。ここでの「有限」は、型と項の代入を許す有限個の局所的な形式です。幅を固定しないすべての具体例が有限個になるという意味ではありません。

目標は、指定した並行な変換経路pとqから、E・R・Γを使った比較図式Hを計算する手続です。ただし、次の入力を要求します。

1. E側の正規化と整合性を、対象の構文について構成します。
2. Eを考慮したRの停止順序と、適切なE正規形へ到達できる条件を証明します。単なる逐次経路の順位を混合構文全体へ流用しません。
3. R同士とR・Eの臨界分岐を分類します。離れた位置の交換、同一の分岐、文脈と代入による事例も網羅します。
4. 各分岐に、既存の基本規則を貼り合わせた具体的な解消図式を与えます。
5. これらの図式が、対象モデルの条件の下で同じ状態対応と割当て誤差を保つことを証明します。計算量的なモデルでは、出力コード・実行証拠・資源と優位性の上界関数について、それぞれ必要な比較を確認します。

Γの基本形式の境界に、図全体の正規化や任意の経路の比較を埋め込みません。既存の `FiniteWiring.Higher` は固定した正規化器に相対的な11形式を持ちますが、その境界は項とともに無制限に大きくなります。`FiniteWiringCoherenceBoundary.boundaries_unbounded` がこの点を証明しています。これを局所的な臨界分岐の列挙が完了した証拠には使いません。

この候補では、抽象的な定理の仮定として「すべての並行経路の比較が存在する」を置きません。それでは求める構成自体を入力にしてしまいます。有限な規則集合であることだけから、有限な臨界分岐の分類を結論することもしません。

## 定理候補B：生成した図式の内部条件を含めて修復します

Hの条件集合S(H)を、すべての局所図式の実例が使う条件と、境界の経路が使う条件の和集合として計算します。中間の経路や局所比較だけに現れる条件も残します。生成器が新しい中間条件を導入する可能性があるため、S(H)をpとqの外側の条件の和集合に置き換えません。

古い条件の解釈をP、新しい解釈をQ、変更した識別子の集合をΔとします。目標となる修復定理の論理的な形は次のとおりです。

- S(H)のすべての条件について、古い証拠Pを持っています。
- Δの外では、古い証拠Pから新しい証拠Qへ移せます。
- `S(H) ∩ Δ` について、新しい証拠Qを与えます。
- 更新後の各モデルについて、使われる局所規則の意味論の契約が成立しています。

以上から、Hを新しいモデルで解釈した比較を得ます。確率的なモデルでは入力状態ごとの条件付きカーネルを比較します。周辺分布の一致だけへ弱めません。計算量的な還元の比較から、分布間の対応を新たに推論することもしません。

有限集合の論理としての修復は、現在の `Requirements.repair` ですでに証明されています。逐次的な高次図式と通常の導出への接続もあります。新しい課題は、候補Aの混合構文・生成されたH・その全内部条件を、この修復と両意味論へ接続することです。更新後のモデルを検証する費用を隠して、集合の交わりだけが修復の全費用だとは主張しません。

## 最初に構成・検査する混合分岐

最初の実装対象は、既存の認証符号の全状態と問い合わせ履歴を残す図です。攻撃者の問い合わせ順序は固定します。箱の周囲での配線変更と、検査済みの局所的な準備順序の交換から開始します。これだけで一般の暗号証明を網羅したとは扱いません。

| 分岐 | 必要な証拠 | 現在の不足 |
|---|---|---|
| 離れた位置での二つの局所変換 | 型を保つ横合成の交換と、条件・誤差の保存 | 状態更新の交換の断片から混合構文への接続 |
| 隣接する交換同士 | 三つの操作の重なりと自己交換の縮約 | 既存の交換の整合性を混合表示へ移す証明 |
| 出力の複製と局所比較 | 同じ一回の実行結果の同時分布を複製する契約 | 再実行との区別を型と規則へ反映する接続 |
| 出力の破棄と局所比較 | 保持する観測、内部条件、誤差・費用の扱いの明示 | 厳密な保存と有向の改善を分けた混合規則 |
| 計算量的な置換と後続の処理 | 実際の還元と、必要なら資源の単調性 | 局所還元の実行証拠を混合構文の解釈へ接続 |

この表は分岐の完全な列挙ではありません。まず混合構文を定義した後、各局所分岐がこの表の事例か、追加の事例かを判定する網羅性の証明が必要です。これを次の実装の第一の判定基準とします。

## 新規性を判定する条件

候補Aの一般原理だけなら、既存の整合性定理の適用である可能性があります。候補Bの集合の交わりだけなら、通常の依存関係の追跡でも得られます。従って、次の三点を別々に確認します。

1. 対象の暗号的な規則について、先行研究から直ちには得られない有限な分岐の構成または保証があるかを調べます。
2. 同じ共有補題・条件情報・局所証拠を与えた通常の方法と比較し、利用者が与える証拠や自動生成・修復の費用に差があるかを確かめます。
3. 一つの認証符号だけでなく、計算量的な仮定を含む別の例でも、定理の仮定を実際に満たせるかを確認します。

現時点では三点とも未達です。図式の節点数の比較結果から、これらを満たしたことにはしません。本研究記録の作成・実装・原典確認にはAIによる支援を使用しました。

## 2026年10月17日追補：投稿の中心候補を判定する仕様

この追補は研究上の提案であり、以下の統合定理を証明済みとはしません。直前の進め方の提案を、現存する宣言と照合して具体化しました。部分的な再検証だけを新規性の候補にすることは撤回します。理由は、通常の共有証明にも同じ依存情報を認めた比較がすでに存在するためです。

### 既存の結果から除外する主張

`InformationScheduleLocalRepairComparison.diagram_repair_iff` は、変更された条件に依存する検査の成功と、更新後の証明の受理が同値であることを示します。同じファイルの `RandomFunctionMACLocalRepair.ordinary_repaired_joint` は、通常の証明側でも修復後の同時分布の等式を証明します。`exact_counts` では、全検査が n+2 件、変更に依存する検査が2件ですが、この差は通常の方法にも利用できます。[実装](../Foundation/Examples/InformationScheduleLocalRepairComparison.lean)に基づく判断です。これは検査義務の件数であり、検査時間の上界ではありません。

従って「局所修復できる」「経路を全列挙しない」「高次構成子が少ない」のいずれかだけでは、本研究の差分を確定できません。高次元固有の漸近的な優位が存在することも、現時点では仮定しません。

### 入力と出力を持つ統合定理の候補

対象体系を T とします。T は型付きの暗号操作と、横合成・抽選済みの値の複製・破棄を含みます。対象範囲を明記した有限な局所図式の集合 Γ を固定します。Γ の境界に任意の経路の比較を埋め込みません。

入力は次のデータです。

1. T の構文、規則、局所図式 Γ、および各規則・図式の識別子付きの条件集合です。
2. 古い条件解釈 P で検証済みの証明経路 p と、その検査証拠を共有して保存したデータです。
3. 有限の編集列 e です。編集を適用した経路 q の境界型は p と一致するものとします。境界が変わる編集には、別途明示した境界の対応が必要です。
4. 新しい条件解釈 Q、変更した識別子集合 Δ、Δ の外で古い証拠を移す処理、および変更に依存する条件の新しい証拠です。
5. Q に対する局所的な意味論の契約です。契約には、共有状態と入力に条件付けた確率的保証、暗号の優位性の上界関数、実際に生成するコードの実行・要求形式・不変条件・停止・資源上限を含めます。変更していない契約を移す証拠と、変更した契約を新たに検証する証拠を分けます。
6. 資源を改善する編集を認める場合、その方向と、後続処理の資源に関する単調性の証拠です。改善を対称な等式として扱いません。

目標は、これらの入力から、次のデータを返す検査可能な手続を構成することです。

- 編集後の経路 q と、p と q の比較を Γ の貼合せから構成した証拠 H を返します。現時点の部分基底で比較できる編集だけを受理する段階と、対象範囲の全編集を扱う完全性の定理を区別します。
- H の内部まで含めた条件集合 S(H) を計算します。再確認対象を S(H) ∩ Δ とし、集合外の証拠の再利用を正当化します。入力の古い証拠が S(H) を覆わない場合は、新たな内部条件の証拠も要求します。
- 任意の相関を持つ過去、共有状態、入力を保持した同時分布について、指定した状態対応と観測の保証を返します。状態の複製は行いません。コード変更を伴う場合、必要な対応関係を明示します。
- 実際に生成するコードの実行証拠と、そのコードが実現する攻撃者に対する暗号の上界を返します。損失関数の保存と、その上界での評価を別々に確認します。
- 新しい時間上限を、新しいコードの停止証拠から返します。旧コードの上限がそのまま成立するとは仮定しません。時間改善を主張する場合は、別途有向の比較を返します。
- 適用できない編集や成立しない条件を受理しません。保証の健全性に加えて、指定した対象範囲内での成功の条件を証明します。

これは現段階では数学的な仕様です。特に、5番の契約をすべて利用者に一括して与えさせるだけでは、自動的な証明構成の寄与になりません。対象の具体的な暗号体系について、どの契約を有限な基本図式で一度証明し、どの契約を個別更新で再確認するかまで構成する必要があります。

### 費用と比較の仕様

証拠の基本図式の使用数だけでなく、図・境界・位置・共有ライブラリの参照を含む符号化を固定します。初回の構成と、更新1回の費用を分けます。

- N は保存済みの証明データ全体の符号長です。共有された部分は一度数え、参照の符号長を別に含めます。
- E は編集列と編集位置の符号長です。
- A は影響する条件および局所契約を探すために実際に参照するデータの符号長です。
- W は新たに生成する証拠と、新しい局所契約の証拠の符号長です。

測定対象は、初期の生成・検査・索引構築・保存量、および更新時の探索・生成・再検査・追加保存量です。再確認する条件が2件でも、その探索に全データを走査すれば探索費用は N に依存します。単なる集合の交わりから更新時間 O(E+A+W) を結論しません。その上界を主張するには、具体的な索引、証拠共有、検査器の費用モデルの証明が必要です。

比較対象の通常の方法にも同じ局所補題、条件の識別子、依存索引、証拠共有、変更情報を認めます。通常の方法の費用が等しくなるなら、その等価性を結果として記録します。優位を主張する場合は、どの入力族で、どの費用に、どの下界または実測差があるかを明記します。全経路を列挙する弱い比較対象だけを用いません。

### 次に検証する順序と判定条件

### 非導出性の定理と、その範囲

[不変量の証明](../Foundation/Logic/Polygraph/StructuralCartesianCoherenceInvariant.lean)は、証明経路に整数の注釈を付けます。左単位則の適用は出力の各原子的成分に1を加え、ほかの根の規則は0を与えます。後ろに置いた配線は注釈をその配線に沿って運び、経路の合成は注釈を加算し、等式証明の逆は符号を反転します。この注釈は機械実行時間・確率・内部条件・証拠容量を表すものではありません。
