# 確率的操作・識別可能性・命題論理への拡張

この段階では、前段階の有限行列による操作等式に、状態・測定確率・補助系・誤差合成を接続します。第4章の部分空間の論理、第5章の観測文脈の論理、無限次元の閉部分空間も対象に含めます。博士論文全体の完全な形式化を無条件の完了条件にはしません。

## 定義の出所と開始条件

Heunen §3.3 の測定はダガー全射であり、確率的装置を直接定義していません。密度演算子、クラウス表示、測定確率、識別可能性は追加の数学です。[Watrous の著者公開稿](https://cs.uwaterloo.ca/~watrous/TQI/TQI.pdf) §2.1–2.3、§3.1・3.3 を参照します。合成可能な鍵配送の安全性は [Portmann–Renner (2014)](https://arxiv.org/abs/1409.3525) と区別して扱います。文献調査と実装には AI の支援を使用しています。

確率的操作は、有限出力記録、正値でトレース1の状態、クラウス演算子の完全性という条件を採用して開始します。安全性の共通基盤では、任意の有限量子補助系と二値測定を許します。誤差は受理確率の差の上界です。トレース距離やダイヤモンドノルムとの同値性を未証明のまま呼び替えません。プロトコル固有の中止条件・公開通信・秘密増幅は、方式を選んだ後の別の実験です。

第4章の開始条件である有限操作モデルの通常ビルドは前段階で満たしています。部分空間の像と逆像、直交補、射影に沿った佐々木随伴を実際に構成します。第5章は今回の明示的な依頼を開始の根拠とし、可換な観測文脈の包含に沿う構成と、その上の直観主義論理を扱います。無限次元も今回の依頼に従って開始し、閉部分空間・有界作用素・閉包の必要性を有限次元から区別します。

## 完了条件

1. 密度演算子、クラウス操作の正値性と任意の有限補助系に対する完全正値性、トレース保存を証明します。前段階の適切な操作を確率的操作へ接続します。
2. 測定の分岐状態、非負の分岐確率、確率総和1、古典出力の記録を構成し、非自明な具体例を検証します。
3. 補助系を含む識別可能性の上界、三角不等式、前後の操作による誤差の保存、逐次合成を証明します。`Presentation` による判断・規則・`Model`・仮定置換を接続します。任意の意味論的真理を無前提で導入する規則は設けません。
4. 第4章の有限次元部分空間の像・逆像・直交補・直交モジュラー則・射影に対する随伴を検証し、対象論理の導出をモデルへ解釈します。
5. 第5章の文脈の包含に沿う構成とハイティング含意の具体的意味を接続します。内部スペクトル、構成的ゲルファント双対性、点の不存在の定理は独立の大きな依存として未達事項に残します。
6. 無限次元では有界作用素の随伴、閉部分空間の直交補、二重直交補と閉包の関係を検証します。有限次元のカップや有限和によるクラウス表示を無条件に無限次元へ流用しません。無限次元のトレース級状態と一般の正常完全正値写像の構成は未達事項として明記します。
7. 原典との対応、追加した仮定、証明の公理依存を記録し、新規モジュールと既存暗号を含む通常ビルドを通します。

## 実装結果

この段階では、有限次元の確率的操作、誤差を扱う対象論理、部分空間の対象論理、観測文脈の対象論理、無限次元の閉部分空間の対象論理を追加しました。核の変更はありません。下表の条件番号は、この文書の完了条件に対応します。以前の設計文書で定めたプロトコル全体の安全性や内部スペクトルの完了条件は削除せず、未達として後段に記録しています。

暗号例の `OneTimePad.lean` は、四つのパウリ鍵による平均操作と理想的な情報消去の操作を、それぞれ別のクラウス族として構成します。補助系を含む全行列要素の一致を計算で証明します。したがって `perfect_privacy` は任意の攻撃者に対して誤差0を与えます。`decrypt_encrypt` は各鍵での復号の正しさです。`protectedOtp` はこの秘密性を後続のゲートと合成する実際の対象論理の導出です。鍵の独立性と一様性は平均チャネルの選び方に固定されています。鍵と入力が相関する場合や、鍵を再使用する場合の定理ではありません。

既存暗号との接続は `ProbabilityBridge.lean` にあります。装置の分岐と攻撃者の受理結果を、既存の `Probability.ProbComp` による確率計算へ変換します。`classicalOutcome_event` と `experiment_acceptance` は観測確率の保存を証明します。`oneTimePad_existing_probability` は既存の `probabilityGap` で優位0を証明します。これは古典観測の意味保存であり、既存の命令列実行系に量子命令や量子計算量の証明を登録したものではありません。

`CoherentBridge.lean` は前段階の等式導出を、密度演算子に作用する正値写像の等式へ保存します。`coherent_auxiliary_sound` は補助系がある場合も扱います。トレース保存には等長性の証明を別途要求します。非正規化カップや振幅の和による `Op.erase` を、物理的な状態準備・廃棄と同一視しません。

各対象言語の推論規則は本実装で再構成したものです。Heunen に同じ推論規則の構文が掲載されているという主張ではありません。量子状態は型付きの操作へ渡す入力です。メタ文脈中の仮定は操作や述語の性質を証明する証拠です。その再使用は未知状態の複製を生成しません。対象式に束縛変数は導入していません。仮定置換は既存の `Derivation.substitute` と `eval_substitute` によって処理します。

## 再利用した数学と依存関係

固定版 mathlib の `Analysis/Matrix/PosDef`、`Analysis/Matrix/Order`、行列のトレースとクロネッカー積を、状態・測定効果・クラウス操作に再利用しました。正値行列の平方根による分解を用いて、正値行列の積のトレースが非負であることを検証しています。内積空間の射影・直交補・閉部分空間・連続線形写像・`l2Space` を第4章と無限次元に再利用しました。C*-代数、星部分代数、順序の圏、型の圏を第5章の文脈の関手に再利用しました。

密度演算子とクラウス操作の正値性から、装置と測定確率を構成します。測定効果の引き戻しと補助系上の合成の整合性を証明した後、識別誤差の前後処理と逐次合成を証明します。その定理を有限規則のモデルに用います。パウリ平均の具体的な計算から秘密性の基本規則の妥当性を証明し、導出を解釈して後続処理を含む秘密性を得ます。部分空間と観測文脈の論理は別のモデルです。二つの論理の判断を同じ命題とみなす変換は仮定していません。

## 未達事項と後続の開始・完了条件

- **量子鍵配送と適応的な安全性**は未達です。方式、公開通信、受理・中止、鍵長と誤差の要件を決めて開始します。完了には鍵の一致、盗聴者への秘密性、有限標本の推定、誤り訂正と秘密増幅、認証された公開通信の具体的な実験と証明が必要です。今回の逐次チャネル合成だけで、対話的な攻撃者・任意回数の呼び出し・並列合成を証明したとは扱いません。
- **量子実行系の登録**は未達です。実際の量子命令と制御・費用の意味論を選んで開始します。`General.ExecutionInterface` 等に対応する実行証拠と観測の意味保存が完了条件です。今回の確率計算への橋渡しはこの条件の代わりではありません。
- **距離と合成の一般化**は、トレースノルムやダイヤモンドノルムを利用する帰着が必要になった時点で開始します。受理確率による定義との同値性、テンソル・対話的な合成、補助系の次元制限をそれぞれ証明する必要があります。現時点では距離の同値性を仮定していません。
- **第4章の抽象化**は、具体的 Hilbert モデル以外への再利用が必要になった時点で開始します。ダガー核圏の一般の KSub、基底変更と射影による輸送、圏全体の関手性の対応定理が完了条件です。有限次元のモデルは今回検証済みです。
- **第5章全体**は、内部スペクトルを用いる命題と量子操作の対応が具体的に必要になった時点で開始します。内部可換 C*-代数の全公理、構成的ゲルファント双対性、ロケールのスペクトル、被覆と状態・確率の対応が必要です。定理5.3.8全体、点の不存在、スペクトル上の全内部論理は未達です。今回の命題論理の健全性をその代替とは扱いません。
- **無限次元の確率的操作**は、無限次元状態を使う方式と収束の位相を決めて開始します。トレース級正値演算子、トレースの連続性、正常完全正値写像、可算測定と確率の収束、適切なエネルギー制約を実際に構成して、今回の有限モデルとの制限・極限の対応を証明することが完了条件です。無界作用素の随伴や定義域も別の課題です。

この区分は以前の未達条件を取り消すものではありません。今回進めた各層の証明と、プロトコル全体・トポス全体・無限次元の確率論の証明を区別して記録しています。

## 実装中に判明した設計上の制約

元の線形操作では任意の入力型・出力型へ零行列を割り当てられます。一方、トレース保存チャネルを全ての型の組へ割り当てることはできません。たとえば1次元から0次元へのトレース保存チャネルは存在しません。誤差の対象言語の変数ゲートは、現段階では同じレジスタ上のチャネルに限定しました。数学側のチャネル、装置、記録、部分トレース、誤差の合成定理は異なる次元にも対応します。将来の変数ゲートの一般化では、実際に使うゲートの入出力だけを指定するシグネチャを用います。量子状態の正規化を緩めて存在しない割当てを作る方法は採りません。

具体的な暗号例として、二つの独立で一様な秘密鍵ビットによるパウリ操作の平均を追加しました。目的は、共通の識別実験で実際の秘密性を検証することです。これは量子ワンタイムパッドの一回の使用に限定します。量子鍵配送における盗聴検出や秘密増幅の代用ではありません。鍵の再使用や鍵自体の公開を許した定理にはしません。
