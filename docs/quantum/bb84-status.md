# BB84 形式検証の区切りと残課題

更新日：2026-10-12。

## 今回の区切り

**認証済み古典通信を前提とする有限次元 BB84 について、具体的な正の出力鍵長、
標準 trace-distance の安全性、無攻撃の物理的な正直実行の成功確率までを証明した状態**
を、今回の形式検証の区切りとします。

| 証明済みの到達点 | 入口となる宣言 |
| --- | --- |
| 操作的距離と標準式 `1/2 Re Tr sqrt(ΔᴴΔ)` の対応 | `Density.stateApprox_iff_traceDistance_le`、`Density.traceDistance_eq_half_traceNorm` |
| 任意の有限クラウス・ブロック攻撃に対する全出力安全性 | `UsefulBB84.secure_half_traceNorm` |
| 65,536ビットの正の出力鍵長、総誤差 `2^-60` 以下 | `UsefulBB84.output_positive` と上記の安全性定理 |
| 実際の無攻撃量子測定と古典記録の分布一致 | `HonestBB84.outcome_eq_records`、`outcome_eq_errorFreeRecords` |
| 訂正・検証・秘密増幅後の全最終量子状態の受理確率 `≥1/2` | `UsefulBB84.honest_success` |
| 固定ソース・固定依存でのビルドと公理監査 | `BB84PaperAudit.lean`、`docs/quantum/reproduce.py` |

具体例は25,165,824信号、3,145,728検査、最低生鍵長8,388,608、一致検証64ビット、
誤り許容0です。公開記録、両者の最終鍵、中止、検証・秘密増幅の種、攻撃者の量子系を
安全性比較に保持します。攻撃は信号ごとの独立操作に限定していません。

主定理の入口は
[`BB84Completion.lean`](../../Foundation/Quantum/QKD/BB84Completion.lean)、
監査入口は [`BB84PaperAudit.lean`](../../Foundation/Quantum/QKD/BB84PaperAudit.lean) です。
依存公理は `propext`、`Classical.choice`、`Quot.sound` の範囲で検査します。
具体的な再現コマンドと内容 ID は [成果物の再現手順](artifact.md) を参照してください。

## 残る形式検証の課題

### 1. 公開通信の認証と鍵消費込みの鍵拡張

現在は認証済み通信がモデルの前提です。実装した線形ハッシュの固定メッセージ衝突補題は、
タグを観測した後の適応的な偽造安全性を保証する完全な認証方式ではありません。

次の完了条件は、公開メッセージの列を扱う具体的認証方式について適応的偽造上界を証明し、
認証失敗誤差を BB84 の安全性誤差へ合成することです。さらに、初期認証鍵と消費した鍵を
会計し、出力秘密鍵が消費量を上回る net key expansion を証明します。
一致検証の64ビットを通信認証のタグや認証鍵消費として数えないことが重要です。

### 2. 雑音下の正直実行の成功確率と鍵率

正直実行の成功確率の定理は、無攻撃・無雑音の恒等送信に対するものです。
具体的な雑音チャネルを定義し、検査通過・復号・一致検証・最終受理の確率を評価する
必要があります。現在の誤り許容0の数値例を、雑音下でも有用な誤り許容とパラメータへ
拡張し、秘密増幅の漏洩予算と合わせて鍵率を評価することが次の完了条件です。

### 3. 合成安全性の明示的な環境・資源モデルへの接続

標準 trace-distance の全出力比較と、既存の物理的後処理の縮小性は証明済みです。
一般の UC／resource security を別途主張するには、実・理想資源、環境、認証通信、
鍵利用プロトコルとの合成を明示し、現在の定理からそのモデルの保証を導く橋が必要です。

### 4. 実装・装置・無限次元モデルへの拡張

現在の BB84 主定理は有限次元の数学的プロトコルに対するものです。
実行可能なプロトコル実装との refinement、光学的な源・検出器・損失・decoy-state 等の
装置モデルとの対応、無限次元の攻撃を扱う拡張は、それぞれ追加の証明対象です。
既存の無限次元作用素基盤があることだけから、BB84 のこの主定理の対象を広げません。

## 論文化・公開に向けた残課題

- **FVQKD の所在確認**：追加調査でも対象論文・主定理を取得できませんでした。
  [固定版コード比較](code-comparison.md)に確認した公開状態と検索結果を記録しています。
  同等成果の有無は未確定であり、世界初の根拠には使いません。
- **独立レビュー**：攻撃モデル、公開情報の順序、安全性定義と物理的実験の仕様を
  外部に確認してもらうこと。Lean-QIT の選択した7ファイルとの比較は済んでいますが、
  外部プロジェクト全体のビルド・公理監査や機械検証済み相互運用は未実施です。
- **公開版の固定**：内容アドレス付きソースアーカイブと再現検証は整備済みです。
  公開リリースタグ、論文と対応する成果物の配布、必要に応じた DOI の発行が残ります。
