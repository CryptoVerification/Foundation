この文書は最初の実装段階の調査と判断を記録したものです。利用者の継続依頼による確率的操作、第4章・第5章、無限次元の実装と残る条件は[拡張段階の設計と結果](extensions.md)に記録しています。以下の「後続」「未実装」は、第一段階完了時の区分です。

## 候補の比較と依存関係

1. **操作の等式と鍵配送ラウンド**を最初に実装します。有限複素行列、テンソル、ダガー、コンパクト構造、古典構造、測定を必要とします。具体的な量子通信の操作と論理導出を同時に検証できるためです。難所は型付きのテンソルの添字、結合子・単位子、共役と転置の区別です。確率を省略する原典の制限は明記します。
2. **核部分対象の動的命題論理**を次に実装します。ダガー核、引き戻し、像、直交補、直交モジュラー性を先に構成する必要があります。存在量化と佐々木随伴までをまとまりとします。測定後の述語の意味を扱うために必要です。難所は部分対象の同型による同一視と、閉部分空間の像の閉包です。
3. **密度演算子と量子操作の確率的意味**を後続候補とします。正値性、トレース、完全正値写像、測定の分岐と古典記録が必要です。これは §3.3 のダガー全射の定義だけからは得られません。原典の定理としてではなく、安全性に向けた追加数学として扱います。
4. **Bohrification** は当面保留します。内部可換 C*-代数、構成的スペクトル、被覆、ロケール、トポスの意味論が必要です。観測の文脈を明示する別の有力候補ですが、今回の鍵配送の操作等式や盗聴者モデルの必要条件ではありません。有限行列で検証した操作等式から第5章の全定理は導けません。
5. **抽象ヒルベルト圏の表現定理**は保留します。加群、体の埋め込み、有界性、完備化を必要とします。具体的な fdHilb の行列によるモデルを使う第一段階に、任意の抽象モデルから複素ヒルベルト空間への埋め込みは不要です。

依存関係は、(a) 圏の合成・テンソルとダガーからコンパクト構造を定義し、(b) 古典構造から古典対象のコンパクト構造を得て、(c) ダガー全射の測定と組み合わせて定理3.3.9を導く、という順です。第4章はこれと別にダガー核から像と引き戻しを構成して KSub の論理を得ます。第5章は C*-代数の可換部分代数の文脈からトポスを構成する経路です。三経路を一つの「量子論理」として無条件に同一視しません。

## 既存のメタ論理と再利用

`Foundation/Logic/Presentation.lean` に `Presentation`、`Context`、`Derivation`、`Model` がすべてあります。独立した `Logic/Model.lean` はありません。`Model.Carrier` は命題にもデータにもできます。規則は有限個の前提を持ちます。`Derivation.substitute`、`eval_substitute`、自由モデルの一意性をそのまま再利用します。`Translation.lean` は規則を導出へ展開し、導出の置換と解釈を保存します。

`Crypto/Logic/Presented/Syntax.lean` は意味論と構文を分けています。`Interpretation.lean` は同じ構文から安全性と証明木を解釈します。`Reconstruction.lean` は既存の一般的導出との往復を証明します。`Resources.lean` は損失と実行証拠を保存します。`CompositeRule.lean` は導出済み規則を `Translation` で展開します。`General/Derivation.lean` の生成計画と証明証拠の分離、`General/Execution.lean` の実行契約、`General/ObservedExecution.lean` の観測実験との一致も調査しました。これらは後の登録の接続点ですが、現在の古典確率の実行系に複素振幅をそのまま登録できるわけではありません。`Examples/PureLogic.lean` と `Examples/TheoryTranslation.lean` は多前提規則、置換、展開の既存の検証例です。`docs/crypto-logic.md` の「意味論に依存しない理論提示への再構成」は核の保証と制限を明記しています。

### 核を変更しない表現

- 判断を「同じ入力型と出力型を持つ二つの操作式の等式」とします。型は式の添字です。量子ワイヤーの順序と使用回数は合成・テンソルの型と構文に保持します。
- 等式の反射・対称・推移と合同規則を対象論理の規則として登録します。操作の等式を、メタ論理の導出木の等式に変えません。導出木そのものは商にしません。
- メタ論理の同じ等式仮定を二回使うことは可能です。それは操作を置き換える証明の再利用です。未知状態を複製する射にはなりません。コピーの射は選んだ古典基底のコピーだけです。
- 今回は項の束縛変数がありません。式の入力型・出力型がワイヤーの文脈です。後に自由変数を導入する場合、束縛と変数代入は対象言語の構文・判断として実装し、その補題を規則にします。メタ文脈の仮定置換と混同しません。
- 任意の意味論上の真理から等式を導入する規則は設けません。測定の条件は明示的な等式仮定とし、具体例では固定したゲートの証明から置換します。
- 有限導出と、極限を含む数学的対象は別です。無限次元の閉部分空間や連続性を一つの判断のパラメータにすることはできます。真に無限個の子導出を持つ規則は現在の `Fin (arity r)` では表現できません。しかし今回その規則は不要です。無限前提の規則を必須とする対象体系が定まるまでは核の拡張を要求しません。

### mathlib の再利用と追加部分

固定版の `Data/Matrix/Mul`、`LinearAlgebra/Matrix/ConjTranspose`、`LinearAlgebra/Matrix/Kronecker` は行列の合成、随伴、テンソルの積の計算を提供します。`Data/Complex/Basic` と有限和を再利用します。`CategoryTheory/Preadditive/Mat` は一般の加法的圏上の行列圏であり、今回必要な複素行列のダガーとコンパクト構造を直接一括で提供するものではありません。標準基底のコピー、削除、カップ、型付きの再添字付け、蛇行等式、フロベニウス則、鍵配送の具体的等式は追加します。

今回、`Analysis/InnerProductSpace/Adjoint` と `Matrix.toEuclideanLin` も再利用し、有限次元複素ヒルベルト空間上の線形写像へ表示しています。行列の共役転置が内積に関する随伴であることを証明しました。`CategoryTheory/Monoidal/Braided/Basic` と `Monoidal/Rigid/Basic` のインスタンスに、行列の対称モノイド構造と双対を実際に登録しています。

## 最初の範囲と完了条件（実装開始前に確定）

第一の範囲は、基底を選んだ有限次元複素空間の操作、および定理3.3.9の有限次元版です。自作の等式論理は原典の図式計算を再構成するもので、原典に同じ推論体系が明示されているとは主張しません。

完了条件は次のすべてです。

1. 型付き操作の合成、テンソル、ダガー、共役、古典基底のコピー・削除、カップ・キャップを定義します。具体的な有限行列で合成の法則、テンソルの交換則、ダガーの法則、コンパクト構造の蛇行等式、古典構造の余モノイド・特殊性・フロベニウス則を証明します。
2. `Presentation` で等式判断と有限前提の規則を定義します。各規則を行列等式へ解釈して妥当性を証明し、`Model` と全導出の健全性を構成します。
3. ダガー全射の条件から定理3.3.9の操作等式を得る実際の導出を作ります。モデルの等式を直接導出の代わりにしません。
4. 恒等射以外で重ね合わせを扱う具体的な測定を構成し、そのダガー全射条件を証明します。上記の仮定付き導出へ具体的な証明を置換し、閉じた導出と行列解釈を検証します。古典コピーが重ね合わせを一般に複製しない具体例も証明します。
5. 仮定置換と解釈の整合性を既存定理から具体化します。操作の等式と導出木の等式の違いを検証例に残します。
6. 宣言と原典の対応表、制限と追加設計を記録します。新規証明で `sorry`、`admit`、独自の公理を使いません。主要定理に `#print axioms` を実行します。
7. 新規モジュールを `Foundation.lean` から参照し、既存の暗号を含む `lake build` を成功させます。核と既存暗号の意味は変更しません。

ここでのカップは原典と同じ非正規化のコンパクト構造です。物理的な規格化されたベル状態の確率分布を与えたとは主張しません。測定も定義3.3.7の意味です。密度演算子の測定装置や破壊的測定の一般形ではありません。任意次元の Hilb や任意のダガー対称モノイド圏での定理3.3.9は今回の完了条件にしません。

## 後続段階の開始条件と完了条件

- **動的命題論理**は、上記の操作モデルを安定してビルドできた後に開始できます。有限次元の部分空間の核・像・引き戻しを実際に構成し、直交補・直交モジュラー性・存在量化の随伴・佐々木随伴を証明します。完了には `Presentation` による順序判断、`Model` の健全性、非可換な測定順序の具体例と、今回の測定射に対する述語輸送を含めます。
- **確率的量子操作**は、扱う出力記録と正規化条件を定めてから開始します。完了には密度演算子、完全正値でトレースを保存または減少させる写像、測定分岐の確率、古典記録との合成、具体的なラウンドの分布を含めます。今回の等式論理との忘却・保存の関係も証明します。
- **安全性と実行系への登録**は、攻撃者が触れる系、公開通信、受理・中止、誤差尺度、合成の要件を定めてから開始します。完了には攻撃者を量化した具体的な実験、鍵の一致と秘密性の別々の定理、誤差の合成則、`General.ExecutionInterface` 等への実際の意味保存証明が必要です。古典機械の計算量証明を量子計算量の証明として流用しません。
- **無限次元と Bohrification** は用途がこれらを必要としたときに開始します。前者の完了には有界作用素、閉像・閉包、極限と完備性の扱いを含めます。後者の完了には対象とする C*-代数のクラス、文脈、内部言語の解釈、原典の対応定理の証明を含めます。単に型を置くことを完了条件にしません。

## 安全性までに残る課題

将来の再利用に関する次の判断は推測です。操作の等式と述語輸送を二層で保持すると、プロトコルの実装変換と測定後の性質を対応させやすくなる可能性があります。具体的な安全性定義を今回の構造の前提にはしません。

原典 §3.3 の正しさだけからは、盗聴者の補助系とのもつれ、識別可能性、トレース距離等の誤差、有限標本の推定、情報漏洩、誤り訂正、秘密増幅、認証された公開通信、反復時の独立性や適応性を得られません。これらは別の数学とプロトコルの証明が必要です。§5.5 の状態と確率の対応も、それだけでこれらの安全性を証明する結果ではありません。
